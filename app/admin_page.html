Admin

Sonarr, Plex, and the rules. Saved in the data folder and applied when you press Save.

Library

The schedule stays in preview until you choose Live and save. Season 1 is always kept. The web port, data folder, and container user are set on the container. Restart after changing those.

Connections

Use the Unraid server IP. From inside this container, localhost is Season Keeper itself. Include a URL base if Sonarr uses one.

Rules

Live deletes later-season files for every show with no play in the watch window, except shows with the ignore tag, and asks Sonarr to download them again when season 1 is played. Season 1 stays.

Access token

Optional. When set, the library page and this page ask for it before a change. Leave the field blank to keep the saved token.
